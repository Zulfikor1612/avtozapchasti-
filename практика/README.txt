Учет продаж автозапчастей
=========================

Состав проекта:
- main.py          — код приложения (Python, Tkinter)
- database.sql     — скрипт создания базы данных
- requirements.txt — список зависимостей

Требования:
- Python 3.11 или новее
- MySQL 8.0 (сервер и MySQL Workbench)

Установка и запуск:
1. Откройте MySQL Workbench и выполните скрипт database.sql —
   будет создана база avtozapchasti с тремя таблицами и тестовыми данными.
2. Установите зависимости: pip install -r requirements.txt
3. Откройте main.py и укажите в строке DB_PASSWORD пароль вашего MySQL-пользователя root.
4. Запустите приложение: python main.py

Сценарий проверки:
1. Вкладка «Клиенты» — добавьте клиента (ФИО и телефон), убедитесь, что строка появилась в таблице.
2. Вкладка «Запчасти» — добавьте запчасть (артикул, наименование, цена, остаток).
3. Вкладка «Продажи» — укажите ID клиента и ID запчасти, количество, оформите продажу.
   Сумма рассчитывается автоматически, остаток на складе уменьшается.
4. В том же разделе введите артикул (можно часть) и нажмите «Поиск».
5. Укажите период дат и нажмите «Отчет» — под таблицей появится итог по количеству и сумме.

Дополнительно можно проверить:
- добавление записи с пустыми полями — выводится предупреждение;
- текст вместо числа в цене или количестве — предупреждение;
- отрицательную цену — предупреждение;
- количество продажи больше остатка — продажа не оформляется;
- удаление клиента или запчасти, на которых есть продажи — база не даст удалить, выводится сообщение;
- удаление любой записи — запрашивается подтверждение.
